# 스킬 올리기 프로토타입

스킬 베이스드 러닝 방향 중 "스킬 올리기"에 캐릭터 · 공유 스킬 카드 · 스킬 배지를 붙여 본 HTML 프로토타입입니다.

- 병아리 버전: `/` (사무실 배경, 병아리 5단계)
- 고놈 버전: `/gonom/` (우주 배경, 우주비행사 5단계, 한 화면 몰입 · 움직이는 배경 · 레벨업 워프)
- 단일 HTML · 예시 데이터 · 빌드 없이 브라우저에서 바로 열림
- 맨 위 검은 바(시연용): 레벨 바로가기, 다음 레벨로 올리기, +30P, 버전 전환
- 스킬 카드 탭의 "이미지로 저장"은 공유용 카드 PNG를 내려받음

> 포인트·레벨 기준·칭호는 모두 임시 값입니다.
